# 오답 노트 (Lessons Learned)

> 작업 중 발생한 실수, 삽질, 교훈을 기록한다.
> **작업 시작 전 이 파일을 읽고, 같은 실수를 반복하지 않는다.**

SessionStart 훅이 이 파일의 최근 30줄을 자동으로 세션 컨텍스트에 주입한다.

---

## 작성 형식

```
### [YYYY-MM-DD] 한줄 제목
- **상황**: 무엇을 하려 했는가
- **실수**: 무엇이 잘못되었는가
- **원인**: 왜 발생했는가
- **해결**: 어떻게 고쳤는가
- **교훈**: 다음에 어떻게 하면 되는가
```
