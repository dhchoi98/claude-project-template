세션을 종료한다. 아래 순서를 정확히 따른다:

**주의: Git 작업(커밋, 푸시, 브랜치 등)은 절대 하지 않는다.**

1. 자가 검증을 수행한다:
   - 테스트 실행 (가능하면)
   - 빌드 확인 (가능하면)
   - 린트 확인 (가능하면)
   - 실패 시 수정 후 재검증
2. 현재 세션에서 수행한 작업을 요약한다
3. `.work/HANDOFF_TEMPLATE.md`를 참고하여 핸드오프 문서를 작성한다:
   - 파일명: `.work/handoffs/{날짜}-S{N}-T{XXX}.md`
   - 날짜 형식: YYYYMMDD
4. 실수나 교훈이 있었다면 `.work/MISTAKES.md`에 추가한다
5. `.work/BOARD.md`를 업데이트한다:
   - 완료 시: `[~S{N}]` → `[x]` + 완료 이력에 추가
   - 미완료 시: 상태 유지
   - 활성 세션 테이블에서 자신을 `idle`로 변경
6. `PLAN.md`의 해당 티켓 상태를 동기화한다

출력:
```
━━━ SESSION END ━━━
세션: S{N}
티켓: T{XXX} — {제목}
상태: {completed | in-progress | blocked}
검증: {PASS | FAIL(사유)}

✅ 완료:
- {작업 1}

📝 핸드오프: .work/handoffs/{파일명}
📌 오답 노트: {추가했으면 요약 / 없으면 "없음"}

⚠️ Git 작업이 필요하면 지시해주세요.
━━━━━━━━━━━━━━━━━━━
```
