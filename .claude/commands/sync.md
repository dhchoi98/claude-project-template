다른 세션의 변경사항을 확인한다.

**주의: git fetch/pull 등 Git 작업은 하지 않는다.**

1. `.work/BOARD.md`를 다시 읽어 변경사항을 확인한다
2. `.work/handoffs/`에 새로운 핸드오프가 있으면 읽고 요약한다
3. 자신이 수정 중인 파일을 다른 세션도 수정했는지 확인한다

출력 형식:
```
━━━ SYNC ━━━
📋 보드 변경:
  - T{AAA}: {상태 변경}
  - T{BBB}: 새로 추가됨

📄 새 핸드오프:
  - S{X}: {요약}

⚠️ 충돌 위험:
  - {파일명}: S{X}도 수정 중
  (없으면 "충돌 위험 없음")
━━━━━━━━━━━━━━━━━━
```
