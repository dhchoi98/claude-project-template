세션을 시작한다. 아래 순서를 정확히 따른다:

1. `.work/MISTAKES.md`를 읽고 이전 세션들의 교훈을 파악한다
2. `.work/BOARD.md`를 읽고 현재 활성 세션과 진행중인 티켓을 파악한다
3. `.work/handoffs/` 폴더의 최신 핸드오프 파일들(최근 5개)을 읽고 다른 세션의 작업 내용을 파악한다
4. `PLAN.md`를 읽고 현재 Phase와 우선순위를 파악한다
5. 사용 가능한 세션 번호(S1~S5)를 결정한다:
   - BOARD.md의 활성 세션 테이블에서 idle 상태인 번호를 선택
6. BOARD.md의 활성 세션 테이블에서 자신의 세션을 `active`로 변경한다
7. 클레임 가능한 티켓을 추천한다:
   - 의존성이 해결된 `[ ]` 상태 티켓
   - 다른 세션의 파일 범위와 겹치지 않는 티켓

출력 형식:
```
━━━ SESSION START ━━━
세션: S{N}
활성 세션: S1(티켓), S3(티켓), ...
━━━━━━━━━━━━━━━━━━━

⚠️ 오답 노트:
- {최근 교훈 요약}

📋 최근 핸드오프:
- S{X}: {요약}

🎯 CC 티켓 (클레임 가능):
1. T{XXX} — {제목} [{유형}]
2. T{YYY} — {제목} [{유형}]

🔧 Cursor 티켓 (DS/Kimi에서 작업):
  T{AAA} — {제목} [{유형}] [DS]
  T{BBB} — {제목} [{유형}] [Kimi]

클레임: /claim T{XXX}
━━━━━━━━━━━━━━━━━━━
```
