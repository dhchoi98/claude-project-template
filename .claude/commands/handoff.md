`.work/handoffs/` 폴더에서 핸드오프 문서를 읽고 요약한다.

인자가 있으면 (`$ARGUMENTS`):
- 세션 번호 (예: S1): 해당 세션의 최신 핸드오프만
- 태스크 ID (예: T001): 해당 태스크 관련 핸드오프만
- "all": 최근 10개 핸드오프 전체

인자가 없으면:
- 최근 5개 핸드오프를 시간순으로 요약

출력 형식:
```
━━━ HANDOFFS ━━━

📄 {날짜} S{N} — T{XXX} ({상태})
   완료: {요약}
   미완료: {요약}
   전달사항: {요약}

📄 {날짜} S{M} — T{YYY} ({상태})
   ...
━━━━━━━━━━━━━━━━
```
