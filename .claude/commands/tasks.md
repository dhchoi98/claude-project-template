`.work/BOARD.md`를 읽고 티켓 현황을 보여준다.

출력:
```
━━━ TICKET BOARD ━━━

🟢 활성 세션:
  S{N}: T{XXX} — {제목} [{유형}]
  나머지: idle

📋 대기 중 (클레임 가능):
  T{AAA} — {제목} [{유형}]
  T{BBB} — {제목} [{유형}] (의존: T{CCC} 완료됨)

🚫 블로커:
  T{DDD} — {사유}

⏳ 진행 중:
  T{XXX} — S{N} (파일: ...)

✅ 완료: {N}/{전체}
━━━━━━━━━━━━━━━━━━
```

현재 Phase 진행률도 막대로 표시한다.
