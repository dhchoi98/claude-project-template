PLAN.md를 읽고 미완료 태스크 현황을 보여준다.

수행 단계:
1. PLAN.md를 읽는다
2. `- [ ]` (미완료) 와 `- [x]` (완료) 항목을 모두 카운트
3. Phase별로 진행률 계산 (있으면)
4. 다음과 같은 형태로 출력:

```
━━━ TASKS ━━━

📋 미완료 (상위 10개):
  - [ ] T001 ...
  - [ ] T002 ...
  ...

✅ 진행률: 12/30 (40%)

🎯 Phase 진행률:
  Phase 1: ████████░░ 8/10 (80%)
  Phase 2: ██░░░░░░░░ 2/10 (20%)
  Phase 3: ░░░░░░░░░░ 0/10 (0%)

━━━━━━━━━━━━
```

5. 마지막에 사용자에게 다음 질문:
   "어떤 태스크를 시작할까? 또는 PLAN.md를 더 보고 싶은 부분이 있는가?"
